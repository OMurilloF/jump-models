# Jump Models — Tactical Long-Only ETF Strategy (V2)

A regime-switching tactical allocation strategy built on Statistical Jump Models (CJM).
The strategy dynamically shifts between equity ETFs and bond/cash instruments based on
bear-regime probabilities, targeting improved drawdown control vs. a 60/40 benchmark (AOA).

## How to Run

Run the four scripts in order from the repo root. Each step saves parquet files that
the next step reads.

### Step 1 — Data Preparation

```bash
python src/data_prep.py
```

Outputs to `Data/processed/`:
`prices.parquet`, `returns.parquet`, `spy_features.parquet`, `vix.parquet`,
`yields.parquet`, `oas.parquet`

---

### Step 2 — Regime Engine (slowest step, ~20–30 min)

```bash
python src/regime_v2.py
```

Fits 41 Continuous Jump Models (CJMs):
- 1 global equity regime (SPY + VIX + yield curve)
- 1 rates regime (synthetic 10y bond returns)
- 38 per-asset equity regimes (one CJM per ETF)

Uses walk-forward expanding windows (5-year minimum training, yearly retrain) to
avoid look-ahead bias. Outputs to `Data/processed/v2/`:
`p_bear_global.parquet`, `p_bear_rates.parquet`, `p_bull_assets.parquet` (+ monthly versions)

---

### Step 3 — Portfolio Construction

```bash
python src/strategy_v2.py
```

Builds monthly portfolio weights using:
- **Regime-gated alpha**: 3-factor momentum z-scores scaled by per-asset bull probability
- **Max-Sharpe optimizer** (scipy SLSQP + Ledoit-Wolf covariance shrinkage)
- **Bond ladder**: duration selected by rates regime
- **Recovery trigger**: caps bear signal during fast V-shaped recoveries

Key constraints:
- Long-only, no leverage
- Equity budget: 50%–80% (scaled by global bear probability)
- Per-name cap: 8% (cash instruments BIL/SHV exempt)
- Emerging markets combined cap: 20%

Outputs to `Data/processed/v2/`:
`v2_weights.parquet`, `v2_returns.parquet`

---

### Step 4 — Backtest Analytics

```bash
python src/backtest_v2.py
```

Produces a full comparison of V2 vs V1 vs AOA benchmark including:
- Overall performance table (CAGR, Sharpe, Sortino, Calmar, MaxDD)
- IS (2010–2019) / OOS (2020–2025) split
- Year-by-year annual returns
- Deflated Sharpe Ratio (López de Prado multiple-testing adjustment)

Outputs to `Data/outputs/`:
- `v2_comparison_report.txt`
- `plots/v2_01_cumulative.png`
- `plots/v2_02_drawdown.png`
- `plots/v2_03_annual.png`

## Strategy Design

### Universe
38 equity ETFs across U.S. sectors (Vanguard sector ETFs) and international markets
(iShares MSCI country ETFs). Bond instruments: EDV, VGLT, VGIT, VGSH, SHV, BIL.

### Regime Detection
Each asset is assigned a bear probability using a **Continuous Jump Model (CJM)** —
a clustering-based HMM variant with a jump penalty λ that controls regime persistence.
Features are exponentially weighted return/risk ratios at 21, 63, and 126-day spans.
Walk-forward inference with `predict_proba_online()` ensures zero look-ahead bias.

### Portfolio Construction
1. **Alpha scores**: equal-weighted z-score of 12-1 momentum, 3-1 momentum, trailing Sharpe
2. **Regime gating**: multiply alpha by per-asset bull probability (reduces exposure to bearish assets)
3. **Max-Sharpe**: SLSQP optimizer maximises `w'μ / sqrt(w'Σw)` subject to constraints
4. **Bond sleeve**: rates-regime CJM selects duration (short duration in rising-yield regimes)
5. **Vol targeting**: scale portfolio to 12% annualised volatility (no leverage)

### Benchmark
AOA (iShares Core Aggressive Allocation ETF) — 80% global equity / 20% global bonds, 0.15% expense ratio.
